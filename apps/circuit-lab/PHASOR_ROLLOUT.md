# Phasor consolidation

The standalone four-lesson page has been retired after UI review.
Circuit Elements now owns the Circuits I and II course sections.

| Previous link | Integrated experiment |
| --- | --- |
| `#phasors=complex` | H2, Phasors |
| `#phasors=series` | H3, Phasors |
| `#phasors=nodal` | H8, Phasors |
| `#phasors=power` | H8, AC power |

Circuit Lab opens its existing frequency-response interface by default.
Existing `#circuit=...` links keep their component settings and output selection.
H8 uses the same schematic, controls, time cursor, solution routes and worked
math as the rest of Circuit Elements. Capacitor voltage and inductor current
initial conditions are adjustable. Phasors describe steady state. The state
route includes initial energy and startup.

The remaining Circuits I and II scope is tracked in
`../../CIRCUITS_I_II_BUILDOUT.md`. Consolidation does not complete that scope.
